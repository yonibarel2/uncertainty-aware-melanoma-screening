## Project

Deep Learning course final project (80% of the grade). **Uncertainty-aware melanoma screening on HAM10000:** a selective classifier that predicts when it is confident and defers uncertain cases to a dermatologist. The baseline (EfficientNet-B0 with focal loss) is compared against MC Dropout and Deep Ensembles.

## Hard Requirements (from the course guidelines)

- Implemented in **PyTorch**.
- A substantial **model-training** component. Using a pretrained model as-is does not count.
- Systematic experiments: a clear baseline, suitable metrics, a comparison of methods, and in-depth analysis.
- **Reproducibility:** organized, readable, documented code with clear run instructions.
- Final report: **at most 5 pages, in English**. It includes each member's contribution and a GitHub link.
- Presentation: **15 minutes**, split equally, and both members present. No reading from a script.
- **Deadline: report and slides on Moodle by 15.10.26.**
- An "excellent" grade requires an original contribution and deep insights. Protect the cost-sensitive defer policy and the failure analysis.

## Methodology Guardrails

- Split by **`lesion_id`**, never by image. Image-level splits leak.
- The **test set is used only for the final evaluation.** All tuning happens on validation data.
- Defer and referral thresholds are chosen on **validation data only**.

## Results and Traceability

- Every number or figure in the report must come from a saved run: its config, seed and metrics.
- Results live in `results/<run>/`, figures in `figures/` (generated by code only).
