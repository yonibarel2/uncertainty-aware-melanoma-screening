# Uncertainty-Aware Melanoma Screening

A selective classifier for melanoma screening on HAM10000: it sends a patient home only when it is confident, and refers everyone else to a dermatologist. We fine-tune EfficientNet-B0 with focal loss and compare a single model, MC Dropout, MC Dropout + StochasticDepth and a Deep Ensemble. Referral cutoffs are chosen on validation by a clinical cost (a missed melanoma = 10, 50 or 100 doctor visits).

Deep Learning course final project, Elhar Brand and Yehonatan Barel. The report is submitted separately.

## Main results (test set)

| | Single model (avg of 5) | MC Dropout | MC Dropout + StochDepth | Deep Ensemble |
|---|---|---|---|---|
| AUC | 0.885 | 0.885 | 0.885 | **0.905** |
| Cost per 1,000 patients, miss = 10 visits | 479 | 467 | 469 | **416** |

Full tables: `results/test_summary.csv`, `results/test_metrics.csv`. Figures: `figures/`.

## Repository layout

| Path | Holds |
|---|---|
| `configs/base.yaml` | every setting (one shared config; the seed is passed on the command line) |
| `src/data.py` | binary label, `lesion_id` split, 224 px image cache |
| `src/model.py` | EfficientNet-B0, focal loss, MC Dropout switch |
| `src/train.py` | trains one model per seed |
| `src/predict.py` | per-photo melanoma %, entropy and mutual information for each method |
| `src/uncertainty.py` | entropy and mutual-information formulas |
| `src/evaluate.py` | cutoffs (validation), test metrics, calibration, failure analysis, figures (no GPU) |
| `results/` | the split, every run's config/history/metrics, all predictions and result tables |
| `figures/` | every figure in the report, generated by `src/evaluate.py` |
| `data/`, `checkpoints/` | dataset and model weights (created when you run the code, not in git) |

## How to re-run

There are two ways. **Option A** rebuilds every table and figure from the saved predictions in about a minute, on any computer. **Option B** reruns everything from scratch, including training, and needs a GPU.

All commands run from the repository root.

### 1. Setup

Python 3.10 or newer.

```bash
git clone https://github.com/yonibarel2/uncertainty-aware-melanoma-screening.git
cd uncertainty-aware-melanoma-screening
pip install -r requirements.txt
```

For Option B, install a CUDA build of PyTorch first (see [pytorch.org](https://pytorch.org/get-started/locally/)). We used PyTorch 2.8 with CUDA 12.8 on an RTX 4090.

### 2. Option A: reproduce the results from saved predictions (no GPU)

```bash
python src/evaluate.py --config configs/base.yaml --step cutoffs    # choose referral cutoffs on validation
python src/evaluate.py --config configs/base.yaml --step test       # apply the frozen cutoffs to test
python src/evaluate.py --config configs/base.yaml --step calibrate  # Platt scaling fitted on validation
python src/evaluate.py --config configs/base.yaml --step failures   # analysis by lesion type
```

This rewrites the tables in `results/` and the figures in `figures/`; they should match the committed versions. The example-photo figure (`--step examples`) also needs the dataset (step 3).

### 3. Option B: full re-run from scratch (GPU)

**Download the data.** HAM10000 from Kaggle:

1. On kaggle.com, go to Settings → API → **Create Legacy API Key**. This downloads `kaggle.json`.
2. Put it in `~/.kaggle/kaggle.json` (Windows: `C:\Users\<you>\.kaggle\kaggle.json`).
3. Run:

```bash
kaggle datasets download -d kmader/skin-cancer-mnist-ham10000 --unzip -p data/ham10000
```

Alternatively, download the zip manually from [the dataset page](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000) and unzip it into `data/ham10000/`. The code needs:

```
data/ham10000/
├── HAM10000_metadata.csv
├── HAM10000_images_part_1/
└── HAM10000_images_part_2/
```

(The lowercase `ham10000_images_part_*` folders in the zip are duplicates and can be deleted.)

**Run the pipeline.** Times are for one RTX 4090.

```bash
# Split by lesion_id and cache all photos at 224 px (~5 min). Writes results/split.csv.
python src/data.py --config configs/base.yaml

# Train the five models, seeds 0-4 (~3-5 min each). Writes results/seed<N>/ and checkpoints/seed<N>.pt.
for s in 0 1 2 3 4; do python src/train.py --config configs/base.yaml --seed $s; done

# Predictions for all validation and test photos (~10 min). Writes results/predictions/.
python src/predict.py --config configs/base.yaml
python src/predict.py --config configs/base.yaml --methods mc_stochdepth

# Evaluation (as in Option A), plus the example-photo figure.
python src/evaluate.py --config configs/base.yaml --step cutoffs
python src/evaluate.py --config configs/base.yaml --step test
python src/evaluate.py --config configs/base.yaml --step calibrate
python src/evaluate.py --config configs/base.yaml --step failures
python src/evaluate.py --config configs/base.yaml --step examples
```

On Windows PowerShell, train with `foreach ($s in 0..4) { python src/train.py --config configs/base.yaml --seed $s }`.

## Reproducibility

- **Split:** by `lesion_id`, fixed seed 42, committed as `results/split.csv`. No lesion appears in two splits (checked in code).
- **Validation only for tuning:** early stopping, referral cutoffs and calibration all use the validation split. The test split is used once, for the final evaluation.
- **Seeds:** each model's seed, config, per-epoch history and metrics are saved in `results/seed<N>/`. MC Dropout passes use a fixed random seed.
- **Determinism:** rerunning predictions on the same GPU type gives identical numbers. Retraining on different hardware can shift results slightly (GPU convolution kernels are not bit-exact).

## Data

HAM10000: Tschandl, P., Rosendahl, C., & Kittler, H. (2018). The HAM10000 dataset, a large collection of multi-source dermatoscopic images of common pigmented skin lesions. *Scientific Data*, 5, 180161.
